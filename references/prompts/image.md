# 图片提示词融合

先保留用户主体、数量、场景、用途、准确文字、构图、配色、风格、比例、参考图和禁止项，再阅读所选正文。准确文字逐字保留，不擅自翻译、改写或加广告语；用户硬约束相互冲突时只问最必要的问题，不让模板替用户决定。

模板可借鉴构图、材质、灯光、视觉层级和具体避坑方法；删除示例品牌、人物、价格、广告语、虚构数值、占位符和无关对象。未指定内容只补必要表现细节，不把模板默认值升级成用户要求。冲突部分删除，适用部分太少就换模板或自拟。

正文暗含参考图依赖时，须核验真实素材，`unknown` 不等于无需素材。图生图要求保留指定人脸或商品却缺图时先询问，未补齐前不提交；不伪造附件 ID，不下载未内置示例图，不谎称看过图。若只是候选模板要求参考图，而用户原需求为文生图，可换模板或自拟，不制造额外素材要求。

按需要组织：主体与用途 → 构图与元素关系 → 风格／材质／光线 → 准确画面文字 → 输出约束 → 必要禁止项。不强塞全部维度，不把“8K、超清”等修饰词当真实分辨率设置。

提交前逐项对照用户原始需求：

- 主体、数量、场景、准确文字和禁止项均保留，冲突、示例与占位符已清除。
- 必需素材真实存在且获准使用，模板隐含依赖已核验。
- 最终 prompt 与 negative prompt、尺寸／比例、count、`--image` 一致；只用当前通路真实支持的参数，不把模板 JSON 当 API 参数。独立负面提示词仅在实际支持时使用，必要禁止项也保留在主 prompt；不承诺模型精确遵守。
- 不增加生成数量或收费任务，不自动试生成或补生；其余规则见 [集成说明](<index.md>)。

例如用户要求“黑色保温杯、白底、极简、16:9、不要文字”，即使命中电商模板，也须删除价格角标和促销标题，只采用兼容的材质、光影与商品构图。
