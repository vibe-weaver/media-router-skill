media-router 配置页面

在这里配置厂商密钥和模型池。配置会写入 skill 目录，AI 助手随后就能用这些模型出图、出视频。

配置都写在哪？（点开查看文件路径）
配置目录：— 模型池：— 生成文件：— 密钥文件：—
先在下面添加你有的厂商，把 API Key 填进去。密钥只会存在你本机的 config/secrets.web.yaml 里（该文件已被 .gitignore 忽略），不会被发送到别处。 你自己手写的 secrets.yaml 和 models.yaml 不会被改动。

不确定就不要填，程序内置了各平台官方地址。
只有「自定义接口（高级）」需要填这块 —— 它没有内置协议，得靠这些参数说明 "请求怎么发、结果从哪儿取"。内置平台（火山、百炼、可灵…）留空即可。
最小可用示例（同步接口，提交后响应里直接带产物地址）： 
{
  "auth": {"type": "bearer"},
  "result_path": "data.images",
  "result_url_field": "url"
}
响应里只有一个地址时可以连 result_path 都不写，程序会自己找。 异步接口（先拿 task_id 再轮询）再加： 
{
  "submit": {"task_id_path": "data.task_id"},
  "poll": {"url": "https://…/{{task_id}}", "status_path": "data.status",
           "result_path": "data.result"}
}
字段含义见 references/providers.md 的 generic_http 一节。
还没有配置任何厂商。请先到「① 厂商配置」添加一个厂商并填入 API Key，再回来添加模型。
同一优先级里的选中概率
权重越大，被分到任务的概率越高。下面会实时显示每个模型的占比。

添加模型

以厂商控制台里显示的模型名为准，手动填写。
图像模型
生成图片。文生图默认支持；勾选后也可用于图生图。
视频模型
生成短视频。文生视频默认支持；勾选后也可用于图生视频。
这里设的是这个模型每次生成的默认尺寸。发请求时也可以在提示里临时指定，临时的优先。 注意：不是每个模型都支持所有尺寸（比如有的只收 1024×1024，有的用「1K/2K/4K」这种叫法）， 以厂商文档为准；填了不支持的值平台会报错。
清晰度和时长直接影响花费：1080p / 10 秒比 480p / 5 秒贵得多。 不是每个模型都支持全部组合（可灵一般 5/10 秒，即梦 3~12 秒），以厂商文档为准。
拖动滑块或直接填数字都行。越大越容易被选中；同一优先级内按权重比例分流，例如 50 和 30 大约是 62% 与 38%。
高级选项
数字越小越优先。优先级 1 的模型永远压过优先级 2 —— 只有前面的都不可用才会轮到后面的。 想按权重分流就都填 1，想设成"主用 + 备用"就给备用模型填 2。
